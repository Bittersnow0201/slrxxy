## World

Private two-person nest under soft lamp light. Rose-tinted warm ground (not cream craft paper), soft ink type, one rose accent, peach glow volumes, soft rounded plates.

## Palette

| Token | Value | Role |
| --- | --- | --- |
| void | `#f6eef1` | page ground (blush mist) |
| void-lift | `#fff7f9` | panels / inputs |
| ink | `#2c2326` | primary text |
| ink-dim | `#7a656c` | secondary text |
| accent | `#c45d72` | single accent |
| accent-deep | `#a3475c` | hover / press |
| glow | `#f0c9b0` | lamp warmth |

Theme lock: light warm. Intro overlay stays briefly dark for video contrast.

## Typography

- Display: Archivo + Chinese system fallbacks
- Body: PingFang / Microsoft YaHei
- No eyebrows, no em-dashes

## Shape

Soft 0.85–1.1rem radii on panels and photos. Pills for primary actions.

## Motion

Soft entrances, gentle glow breathe, scroll reveals. Honor reduced motion.
